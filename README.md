# IT Event & System Monitoring Lab

## Overview
This was a hands-on Windows administration lab where I practised using built-in tools to monitor system activity, check event logs, and troubleshoot common issues.

## Tools Used
- Windows Event Viewer
- Task Manager
- Reliability Monitor
- Performance Monitor
- Windows Defender
- Task Scheduler

## What I Did
- Generated system events and checked Windows logs.
- Disabled and re-enabled Wi-Fi to observe network activity.
- Monitored CPU and memory usage using Task Manager.
- Checked security events and explored Windows Defender logs.
- Investigated an unexpected shutdown using Reliability Monitor.
- Explored performance counters and alert configuration.
- Reviewed startup applications and their impact on system performance.
- Practised custom logging and scheduled task configuration.

## What I Learned
This lab helped me understand how to use Windows tools to monitor system performance, investigate errors, and follow basic troubleshooting steps. 
It also gave me practical experience with event logging and system administration.
